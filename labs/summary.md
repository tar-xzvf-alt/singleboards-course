# Резюме лабораторных работ
## Курс: Linux на встраиваемых устройствах (RISC-V, Allwinner D1)

---

## Лабораторная №1
### Освоение базовых навыков работы с одноплатником

**Цель:** Подключение к плате через UART, выполнение базовых операций в консоли.

**Основные темы:**
- Одноплатные компьютеры на базе Allwinner D1 (Lichee RV Dock, MangoPi MQ Pro)
- Архитектура RISC-V vs x86_64 (RISC vs CISC, открытый ISA)
- Подключение через UART-преобразователь (3.3V)
- Работа с утилитой tio
- Базовые команды Linux: lscpu, free, df, ip, mkdir, cat

**Оборудование:** Lichee RV Dock, UART-преобразователь

---

## Лабораторная №2
### Работа с платой по SSH

**Цель:** Удалённое взаимодействие с одноплатником через SSH.

**Основные темы:**
- Протокол SSH (Secure Shell)
- Протокол SCP для передачи файлов
- Настройка Wi-Fi/Ethernet на плате (nmcli)
- Создание пользователей в Linux
- Конфигурация sshd

**Результат:** Удалённый доступ к плате без UART

---

## Лабораторная №3
### Использование кросс-компилятора

**Цель:** Сборка программ для RISC-V на x86_64 машине.

**Основные темы:**
- Кросс-компиляция и тулчейны
- Установка gcc-riscv64-linux-gnu
- Компиляция: `riscv64-linux-gnu-gcc -o file file.c`
- QEMU user-static (binfmt) для запуска RISC-V бинарей
- Статическая линковка с флагом -static

**Результат:** Исполняемый файл для RISC-V, собранный на x86_64

---

## Лабораторная №4
### Создание основных компонентов образа. Ядро Linux

**Цель:** Изучить структуру ядра и собрать его под RISC-V.

**Основные темы:**
- Ядро Linux: управление ресурсами, файловые системы, сеть
- make menuconfig — интерактивная настройка
- ARCH=riscv, CROSS_COMPILE=riscv64-linux-gnu-
- Патч PREEMPT_RT для реального времени
- Выбор SoC: ARCH_SUNXI / sun20i, поддержка Wi-Fi (RTW88_8723DS)
- Сохранение .config

**Результат:** Собственное ядро для Lichee RV Dock

---

## Лабораторная №5
### Компоненты образа: дерево устройств, корневая ФС, загрузчик

**Цель:** Подготовить все компоненты для образа ОС.

**Основные темы:**
- Device Tree (DTS/DTB) — описание железа
- Загрузчик U-Boot (SPL + U-Boot Proper)
- OpenSBI — Supervisor Binary Interface (M-mode)
- Сборка u-boot-sunxi-with-spl.bin
- extlinux.conf — конфигурация загрузки
- Rootfs — корневая файловая система (ALT Linux)

**Результат:** Все компоненты образа готовы

---

## Лабораторная №6
### Подготовка носителя и запись образа

**Цель:** Собрать полноценный загрузочный образ и записать на SD-карту.

**Основные темы:**
- Разбивка SD-карты: BOOT (FAT32) + ROOTFS (ext4)
- Запись загрузчика: `dd if=u-boot-sunxi-with-spl.bin of=/dev/sdX bs=1k seek=8`
- mkfs.vfat, mkfs.ext4
- Структура BOOT: Image, .dtb, extlinux/
- Распаковка rootfs: `tar -xJpf rootfs.tar.xz`

**Результат:** Рабочая SD-карта с ALT Linux

---

## Лабораторная №7
### Добавление поддержки SPI-интерфейса

**Цель:** Включить SPI на плате для взаимодействия с периферией.

**Основные темы:**
- SPI (Serial Peripheral Interface): MOSI, MISO, SCK, CS
- Модификация Device Tree (spi1 на выводах PD10-PD15)
- Драйверы ядра: SPI_SUN6I, DMA_SUN6I, SPIDEV
- Активация в .dts файле: `status = "okay"`
- Тестирование замыканием MOSI/MISO

**Результат:** Устройство /dev/spidev* для работы с SPI из userspace

---

## Лабораторная №8
### Добавление поддержки I2C-интерфейса

**Цель:** Включить I2C (TWI) для подключения датчиков и дисплеев.

**Основные темы:**
- I2C/TWI: SDA (данные), SCL (синхронизация), ведущий/ведомый, адресация
- Device Tree: i2c2 на пинах из банков PE/PG
- Драйверы ядра: I2C_MV64XXX, I2C_CHARDEV (+ I2C, I2C_MUX)
- Подключение OLED-экрана SSD-1306
- Python-библиотека luma-oled, утилита i2cdetect

**Результат:** Устройство /dev/i2c-*, вывод на экран

---

## Лабораторная №9
### Работа с логическими анализаторами

**Цель:** Анализ цифровых сигналов и протоколов.

**Основные темы:**
- Логический анализатор vs осциллограф
- Sigrok/PulseView — программное обеспечение
- Декодирование UART (115200 8N1)
- Библиотека libgpiod2 для GPIO
- GPIO: gpiochip, линии, потребители
- Генератор меандра на GPIO (PE16, линия 144)

**Результат:** Анализ сигналов, генератор импульсов

---

## Лабораторная №10
### Arduino. Основы программирования микроконтроллеров. Часть 1

**Цель:** Освоить базовые принципы программирования микроконтроллеров.

**Основные темы:**
- Программирование bare-metal vs разработка под ОС
- Архитектура ATmega328P (16 МГц, 32 КБ flash, 2 КБ RAM)
- Загрузчик (bootloader) Arduino
- Скетч: setup()/loop(), pinMode, digitalWrite
- Аппаратные прерывания (LOW/CHANGE/RISING/FALLING), volatile
- Преобразователь логических уровней 5V↔3.3V

**Результат:** Программы «светофор» и «повторитель меандра» с Lichee

---

## Лабораторная №11
### Интеграция Arduino и Lichee RV Dock по SPI с датчиком BME280

**Цель:** Связать Arduino (slave) и Lichee (master) по SPI, передать данные датчика.

**Основные темы:**
- SPI slave на ATmega328P: регистры SPCR (SPE, SPIE, MSTR), SPSR (SPIF), SPDR
- Чтение BME280 по I2C на Arduino (GyverBME280)
- Передача трёх float серией однобайтовых транзакций
- struct.unpack("<fff", data) на Lichee (little-endian)
- spidev (xfer2), преобразователь уровней HV↔LV

**Результат:** Данные датчика поступают с Arduino на Lichee по SPI

---

## Лабораторная №12
### Протокол MQTT

**Цель:** Освоить протокол MQTT и построить распределённую IoT-систему.

**Основные темы:**
- Архитектура «издатель-подписчик» (Pub/Sub), брокер
- Брокер Mosquitto на Lichee (listener 1883, конфигурация)
- Топики, wildcard-подписки (`+`, `#`)
- Уровни QoS (0/1/2), retained- и will-сообщения
- Python-клиент paho-mqtt (python3-module-paho)
- C-клиент libmosquitto (нативная сборка на Lichee)

**Результат:** Распределённая система мониторинга (издатель на Lichee, подписчик на ПК)

---

## Лабораторная №13
### Итоговое проектное задание по вариантам

**Цель:** Самостоятельно спроектировать и реализовать распределённую систему, объединяющую одноплатник, микроконтроллер и GUI-приложение на ПК.

**Формат:** 10 вариантов заданий. Каждый студент получает один вариант. Транспорт между компонентами — протокол MQTT (брокер Mosquitto на Lichee).

**Примеры заданий:** метеостанция с датчиком BME280, пульт управления светодиодами, дашборд системных метрик, генератор сигналов с верификацией анализатором, светодиодный проигрыватель мелодий, система оповещения, консольный сборщик SD-образов, звуковая сигнализация, самописец данных на SD-карту, игра на реакцию.

**Результат:** Полноценный проект, демонстрирующий владение всеми компонентами курса.

## Логика курса

```
Основы              Системное ПО / образ        Периферия              Отладка
─────────           ────────────────────        ───────────            ───────
1 UART ─▶ 2 SSH ─▶ 3 Кросс ─▶ 4 Ядро ─▶ 5 DT/UBoot ─▶ 6 Образ ─▶ 7 SPI ─▶ 8 I2C ─▶ 9 Лог. анализ
                                                                                       │
                           Микроконтроллеры и интеграция              Сети и IoT        ▼
                           ─────────────────────────────              ──────────
                           10 Arduino ─▶ 11 Arduino+Lichee ─▶ 12 MQTT ─▶ 13 Итоговый проект
```

**Блоки:**
1. **Основы (1–3):** Подключение/UART, SSH, кросс-компиляция
2. **Системное ПО и образ (4–6):** Ядро Linux, компоненты образа (Device Tree, U-Boot, OpenSBI), запись на носитель
3. **Периферия (7–8):** SPI, I2C
4. **Отладка (9):** Логический анализатор, GPIO/libgpiod2
5. **Микроконтроллеры и интеграция (10–11):** Arduino bare-metal, связка Arduino↔Lichee по SPI (BME280)
6. **Сети и IoT (12):** MQTT/Mosquitto, распределённая система
7. **Проект (13):** Итоговое задание по вариантам
