**I2C: OLED и сканирование шины. Часть 2/2**

На Lichee I2C прячется под названием TWI (Two-Wire Interface — лицензионный обход торговой марки Philips). На распиновке ищи `TWI2_SDA` и `TWI2_SCL`. Это I2C-контроллер номер 2 (нумерация с нуля), который после активации в ядре и DT появится как `/dev/i2c-2`.

Чтобы включить, добавляем в конфиг ядра четыре параметра:
- `I2C` — базовая поддержка шины
- `I2C_MUX` — поддержка I2C-мультиплексоров, если они есть в схеме или требуются зависимостями
- `I2C_MV64XXX` — драйвер конкретного контроллера (Allwinner использует Marvell-совместимый)
- `I2C_CHARDEV` — доступ к шине из userspace через `/dev/i2c-*`

После пересборки можно сканировать шину:
```
i2cdetect -y -r 2
```

Выведет таблицу 16×8 адресов. В ячейках с обнаруженными устройствами — их адреса. Если пусто — проверяй проводку.

Подключаем OLED SSD-1306 (128×64, монохромный, 0x3C). На Python через luma-oled:

```python
from luma.core.interface.serial import i2c
from luma.core.render import canvas
from luma.oled.device import ssd1306

serial = i2c(port=2, address=0x3C)
oled = ssd1306(serial)
with canvas(oled) as draw:
    draw.text((0, 0), "T: 25.1 C", fill="white")
    draw.text((0, 16), "H: 48.3 %", fill="white")
    draw.text((0, 32), "P: 1004 hPa", fill="white")
```

Физический экран за три доллара, на который ты выводишь данные с реального датчика — это момент, когда embedded-разработка перестаёт быть абстракцией.
