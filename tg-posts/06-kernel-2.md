**Собираем ядро Linux: компиляция и загрузка. Часть 2/2**

Когда конфиг готов — запускаем сборку:

```
make ARCH=riscv CROSS_COMPILE=riscv64-linux-gnu- -j$(nproc)
```

`ARCH=riscv` говорит системе сборки, что мы собираем не для x86, а для RISC-V (исходники для разных архитектур лежат в разных поддиректориях). `CROSS_COMPILE` — префикс кросс-компилятора. `-j$(nproc)` — распараллеливаем на все ядра.

Ждём 20-40 минут в зависимости от процессора. На выходе — `arch/riscv/boot/Image` (обычно несжатый образ ядра; сжатые варианты называются отдельно, например `Image.gz`). Плюс Device Tree Blob — бинарное описание железа (о нём отдельный пост).

Этот `Image` нужно положить на SD-карту в раздел BOOT вместе с `.dtb` и проверить путь в `extlinux.conf`. При следующей загрузке U-Boot подхватит новое ядро. После перезагрузки `uname -r` покажет версию собранного ядра.

Что обычно включают для Lichee:
- `ARCH_SUNXI` — поддержка чипов Allwinner
- `RTW88_8723DS` — драйвер Wi-Fi (без него плата без сети)
- `PREEMPT_RT` — real-time патч
- `SPI_SUN6I`, `DMA_SUN6I`, `SPIDEV` — SPI и DMA (нужны оба, без DMA контроллер SPI не стартует)
- `I2C`, `I2C_MUX`, `I2C_MV64XXX`, `I2C_CHARDEV` — I2C

Когда `uname -a` показывает твой kernel release, а плата грузится с новым набором драйверов — это особое чувство. Ты не просто поставил пакет, а собрал центральную часть системы.
