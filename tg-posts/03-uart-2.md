**UART на практике: tio и первые команды. Часть 2/2**

Подключаемся:
```
tio -b 115200 /dev/ttyUSB0
```

115200 — скорость в бодах (бит/с). Это стандартная скорость для консолей Allwinner. Формат кадра — 8N1: 8 бит данных, без контроля чётности, 1 стоп-бит.

И тут начинается магия: сыплются логи загрузчика U-Boot, потом OpenSBI (M-mode firmware, который передаёт управление ядру), потом ядро обнаруживает rootfs, монтирует разделы и выдаёт приглашение:

```
lichee-rv login:
```

Вводишь root и пароль — и ты внутри. Теперь можно смотреть, что за зверь попался:

```
lscpu
```
Покажет `Architecture: riscv64`, одно ядро, 1 ГГц, little-endian. Подтверждение, что перед тобой RISC-V, а не ARM или x86.

```
free -h
```
256 МБ RAM. Из них доступно около 200 — остальное занято ядром и зарезервировано под DMA и framebuffer. Немного, но для Python-скриптов хватает.

```
df -h
```
Корень на SD-карте. Обычно ext4, размер зависит от карты.

```
ip a
```
Смотрим сетевые интерфейсы. Если Wi-Fi ещё не настроен — висит без IP.

UART останется с тобой навсегда. Если сломаешь сеть или ядро — только через него и чинить. Это fallback, который работает всегда.
