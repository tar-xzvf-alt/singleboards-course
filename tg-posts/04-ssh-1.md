**SSH — поднимаем сеть на безголовой плате. Часть 1/2**

UART — это как последовательный кабель от модема в 90-х. Работает, но таскать за собой USB-переходник и три провода неудобно. Хочется открыть ноутбук, подключиться по Wi-Fi и работать.

Первым делом настраиваем сеть. На плате крутится NetworkManager, так что всё делается через nmcli:

```
nmcli dev show
```
Узнаём имя Wi-Fi-интерфейса. Обычно `wlan0`.

```
nmcli dev wifi
```
Сканируем доступные сети. Видим список SSID с уровнями сигнала.

```
nmcli dev wifi connect "МояСеть" password "мой_пароль"
```
Подключаемся. NetworkManager запоминает сеть и будет переподключаться автоматически при загрузке.

Проверяем, что появился IP:
```
ip a | grep "inet "
```
Видим что-то вроде `192.168.1.50/24` — всё, плата в сети.

Теперь с любого устройства в той же сети можно подключиться:
```
ssh root@192.168.1.50
```

Но есть нюанс: на свежих сборках ALT Linux может быть запрещён вход root или парольная аутентификация по умолчанию. Лечится правкой `/etc/openssh/sshd_config` и перезапуском `systemctl restart sshd`.
